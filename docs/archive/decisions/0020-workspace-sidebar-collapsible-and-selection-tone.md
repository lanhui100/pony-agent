# 0020 侧边栏工作区会话折叠与选中高亮浅色化

Status: implemented

## 背景

侧边栏采用工作区三级树组织会话后，出现两项用户体验反馈：
1. 侧边栏当前选中项（会话行与设置入口）的背景底色（原 `#f3c98d`）视觉对比过深，与整体暖色极简调性不够协调，希望统一为与悬停态（hover）一致的浅色。
2. 随着各工作区下对话累积，列表纵向拉长，无法按工作区收起名下会话，需支持可折叠归属会话能力。

## 决策

1. **选中背景浅色化**：将 `menuSelectedClass` 的背景色由 `#f3c98d` 调整为与 hover 相同的浅暖色 `#f6dfb8`，文字保持中高对比深色（`text-stone-900`），保证选中态呼吸感与统一性。
2. **工作区二级组会话折叠**：
   - 保持「工作区」一级大标题行不可折叠不变。
   - 二级各工作区组行支持折叠与展开其名下的三级会话列表：头部提供折叠指示箭头（展开时顺时针旋转 90 度），支持点击指示箭头或点击整行头部直接切换折叠状态（行内重命名态与动作按钮除外）。
   - 折叠状态通过 `pony-agent.session-sidebar-workspace-groups-collapsed.v1` 在客户端 localStorage 本地持久化，按工作区 ID 集合存储。
   - 当用户在已折叠的工作区内点击新建对话时，自动展开该工作区，确保新对话即时可见。
   - 删除工作区时，同步清理其在折叠持久化集合中的残留键值。

## 候选方案

- **纯内存折叠态 vs 本地持久化**：
  - 纯内存折叠态（仅 `ref<Set<string>>`）：应用重启或重载后折叠状态全部复位，用户需反复手动折叠整理好的工作区，体验不连贯；
  - 本地持久化（选用）：将折叠工作区 ID 集合落入客户端 localStorage，多会话多工作区场景下保留用户视线组织偏好，开销极小且无后端依赖。
- **选中态继续保留色相差 vs 完全等同 hover 色**：
  - 保持色相差但略微变浅（如选其他中间调十六进制值）：增加色彩阶层复杂度，容易在多处组件产生色阶噪音；
  - 完全对齐 hover 底色 `#f6dfb8`（选用）：直击用户明确要求，选中行配合文字加粗及文字深色，既消除深色色块突兀感，又保持清晰识别度。

## 影响

- 前端：`HomeSessionSidebar.vue` 交互与样式调整，新增 `pony-agent.session-sidebar-workspace-groups-collapsed.v1` 存储键。
- 纯数据层 `sidebar-groups.ts` 无结构变更，不影响后端持久化与事件流。
