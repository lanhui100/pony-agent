# 系统设计蓝图：波次 4 ACP 协议与技能生态治理

**状态**: 草案
**日期**: 2026-11-12
**架构负责人**: Lead

## 1. 目标与产品边界
- **目标**：实现 ACP 宿主接入，打通 SDK 跨进程通信，完成日志结构化迁移并治理技能生态技术债务。
- **Non-Goals (非目标)**：本次不重构现有的 agent-core 核心调度逻辑，不引入新的远程执行引擎。

## 2. 系统拓扑与模块契约
- ACP 接入模块：负责 `crates/pony-agent-core/src/acp` 的宿主通信链路（ACP 协议）。
- 结构化日志：全局替换 `eprintln!` 为结构化日志记录器（Sentry/Loki 兼容）。

## 3. 核心数据模型与状态流转
- ACP 事件流模型：定义 `ACP_EVENT_SCHEMA` (JsonSchema)。
- 日志输出契约：`{"level": "...", "timestamp": "...", "message": "...", "trace_id": "..."}`。

## 4. 关键技术选型与 ADR
- ADR-0106: 选择 ACP 协议的传输层协议方案。

## 5. 任务分解映射
- B084: ACP 接入
- B085: SDK 驱动
- B087: 结构化日志迁移
- B075~B086: 技能债务治理
