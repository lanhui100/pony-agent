# ADR 0105：TUI 启动页品牌标缩为原尺寸 1/3（Rich 9×10 / Compact 7×8）

Status: implemented

日期：2026-11-09
关联：[0098](0098-tui-splash-master-truecolor-bitmap-first.md)（真色表 + 位图优先，本次只改尺寸）、
[0080](0080-tui-splash-protocol-env-only-detection.md)（零 I/O 协议判定，不变）；
真值源仍为 `src-tauri/icons/icon-master-approved.png`。

## 背景

启动页品牌标在 26 列 × 15 行（Rich）下占地过大：空态一屏被品牌画吃掉近半，且用户实测边缘锯齿明显。
用户诉求是「缩放为当前的 1/3」。

尺寸是生成脚本里的**单一档位常量**（`TIERS`），覆盖率表、母版真色表、图形协议位图三份产物都由它派生，
因此缩小尺寸必须改生成参数并重跑脚本，而不是在渲染层临时缩。

## 候选方案

- **A（采纳）两档统一按线性 1/3 缩放 + 重跑生成脚本**：Rich 26×30 → 9×10（9 列 × 5 行字符，设备像素
  72×80，宽高比 0.900 vs 母版 0.895），Compact 20×22 → 7×8（7 列 × 4 行，56×64，0.875）。
  三份产物同源重生成，`--check` 幂等门禁不变。
- **B（落选）按面积 1/3 缩放（线性 ≈ 0.58，约 15 列 × 9 行）**：用户说的是「缩放为 1/3」，
  按面积缩在视觉上仍有半个屏幕宽，等于没解决「太大」；线性口径也与「锯齿」这一线性维度问题一致。
- **C（落选）只改渲染层 `SPLASH_IMAGE_COLS/ROWS`，位图与覆盖率表保持 26×30**：位图画布密度
  （32×64 px/格）对 1/3 的显示面积已过采样，看着可行；但字符画回退路径的栅格由覆盖率表决定，
  只改位图矩形会让两条路径尺寸分裂（图形终端 9 列、普通终端 26 列），违背 ADR 0098 的单一真值源。
- **D（落选）保留尺寸、改母版重采样参数（提高超采样或换滤波器）压锯齿**：锯齿感主要来自
  footprint 过大（一屏占比高、每格像素被拉伸），单纯改滤波器不改观感尺度，没有回答用户诉求。
- **E（落选）删除品牌画，只留定位语 + 命令入口**：启动页身份缺失，属过度收缩（同 0098 的 D 项）。

## 决策

1. `scripts/generate-splash-logo.py` 的 `TIERS` 改为 `[("RICH", 9, 10), ("COMPACT", 7, 8)]`，
   两档仍是母版宽高比附近的整数栅格；`splash_coverage.rs`、`assets/splash-logo.png` 由脚本重生成
   （位图 832×960 → 288×320）。
2. 图形协议位图矩形随之变为 9×5 字符（`SPLASH_IMAGE_COLS/ROWS` 由 Rich 档常量派生，无需手改），
   仍只在 Rich 档铺位图；Compact 的 7×4 占位与位图矩形不重合，`use_image = tier == Rich` 判据不变。
3. 高度阶梯阈值**保持** 28 / 24 行（ADR 0098 的 28 / 24）。本次只缩品牌画，不动降级阶梯；
   缩小后 Rich 构图共 17 行、Compact 16 行，两档阈值内余量更充足。
4. 门禁按新分辨率校准，并从「绝对个数」改为「占比」，避免下次改尺寸再手调常数：
   `splash_master_rgb_keeps_master_colors` 的有效子像素判据改为占比 ≥ 20%，
   `splash_master_rgb_differs_from_canvas` 改为「与画布色有差的占比 ≥ 90%」；
   档位尺寸、位图尺寸断言更新为 9×10 / 7×8 / 288×320。

## 后果

- 视觉 footprint 26×15 → 9×5 字符（原 1/3 线性），空态留白回归定位语与命令入口。
- 内嵌体积：`splash_coverage.rs` 19074 → 3205 字节，`splash-logo.png` 176332 → 42359 字节。
- 观感风险：9 列分辨率下折带细节被压平，非真彩终端（硬阈值、无 AA）的半格颗粒感更明显——
  这是尺寸决策的既知代价，若后续要「小而不糊」需回到分辨率/超采样参数（候选 D）另开一篇。
- 撤销点：回改 `TIERS` 为 26/30、20/22 并重跑脚本，再把三条门禁的数值改回原值即可。
