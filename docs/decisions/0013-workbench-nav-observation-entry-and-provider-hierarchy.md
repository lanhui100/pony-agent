# 0013 工作台导航精简：观测右栏浮动入口、配置页收敛与提供商页层次折叠

Status: implemented

## 背景

ADR 0009 确立的工作台信息架构运行后出现新的使用反馈：左栏一级键中"模型配置"与"遥测/指标"占据常驻导航心智，但前者在配置页已有对应 tab，后者的数据面向特定对话的回看场景而非常驻入口；同时 ProviderConfigPage 左列"提供商手风琴 + 右侧单编辑器"结构在提供商/模型数量增长后层次不清。本篇修订 0009 中关于两个入口位置的决定，并新增模型页内部布局契约。行为契约以 `openspec/specs/workspace-shell-navigation/spec.md` 为准。

## 候选方案

**观测（原遥测）入口位置**

- 维持左栏一级键：落选——用户裁决移出左栏（该键数据对应特定对话，非跨对话常驻需求）。
- 右栏底部/顶部按钮且随 `<1000px` 强制隐藏：落选——即 0009 曾以 UX P1 否决的"窄窗口零入口"，原样复刻不可接受。
- **对话页右栏右上角纯图标浮动按钮，任何窗口宽度常显（采纳）**：位于折叠按钮左侧（`right-[3.25rem]`）；`<1000px` 折叠按钮消失时观测按钮落位 `right-3`，保证任意宽度可达——正面化解 0009 的否决理由，并以 App.spec 的 960px 断言钉死。
- tooltip 承载更名：复用 `ui/Tooltip.vue`（side=bottom）显示"观测"；aria-label 同步，弥补仓库既有图标按钮仅靠 title 的欠账。

**更名口径**

- 仅改入口文案、页面标题保留"遥测"：落选——同一界面两套名称增加解释成本。
- **入口、页头统一为"观测"；tab 与内容标签保留 Trace / 指标（采纳）**：work 模式页头从"指标"改为"观测"后，门禁差异由 tab 集合表达（trace coding 专属），标题不再承担门禁语义。工作模式卡片描述（ConfigGeneralSection）同步改写；ModelMonitorPage 内嵌头"模型监控"→"指标监控"以贴近 tab 名。

**观测数据会话级口径**

- metrics 随当前会话过滤：落选——ModelMonitorPage 为全局聚合读面（`model-monitor-telemetry` spec），改为会话过滤是未被要求的新功能。
- **沿用现状并在本篇明示口径（采纳）：Trace tab = 当前会话 turn 数据；指标 tab = 全局聚合（支持按会话下钻）**。"数据对应特定对话"对 Trace 成立、对 metrics 以"可下钻到会话"满足。

**"模型配置"一级键去留**

- 保留双入口（左栏键 + 配置页 tab）：落选——同一目的地两个常驻入口，冗余。
- **仅保留配置页"模型" tab（采纳）**：左栏一级键删除（含折叠态图标）；`SidebarNavigationPage` 类型收窄为 `"home" | "settings"`，config·models tab 派生高亮为空（与 tools 一致）。

**ProviderConfigPage 布局**

- 视觉双卡片 + 单一活动区（右侧仍按 entity 整体切换）：落选——不满足用户明示的"两个一级折叠区"，且编辑对象歧义依旧。
- **真双 section 渲染矩阵（采纳）**：
  - 左列扁平化（去手风琴），点击即选中；
  - "提供商详情"section 恒承载 provider view/edit/create 三态，动作按钮（编辑/取消/删除/保存）随迁至 section 头部；
  - "模型列表"section 列出全部模型行，行内展开即"模型配置详情"；行内动作条按态渲染 编辑/删除（视图）或 取消/保存（编辑）；"新增模型"表单卡置于列表顶部；
  - 页头 h2 只承载当前提供商名（create 态"新增提供商"），消除与 section 标题的同名重复。
- 模型编辑/创建表单标记在创建卡与展开行各存一份（互斥渲染，需同步维护）：接受此受控重复，避免为单一消费方拆子组件引入 props/emit 契约。
- 折叠实现就地 button + v-if + aria-expanded/aria-controls（对齐 PlanPanel 受控先例），不复活无人引用的 CollapsiblePanel；编辑中锁定所在区折叠，杜绝"保存指向不可见表单"。模型行在任一编辑态禁点，列表内不再存在静默丢弃未保存输入的路径（左列提供商切换维持既有覆盖语义，见影响节）。

**实施迭代（同日用户反馈，随本篇一并落地）**

- 观测浮动按钮与右栏折叠按钮同规格（h-8 w-8、同底色/圆角/hover），保持双芯片视觉同族。
- 两个一级折叠区与模型行的折叠开关为纯图标 chevron：一级区置于标题左侧、随头部行垂直居中；模型行 chevron 归入行尾动作簇。锁定说明挂外层 span 的 title（disabled 控件 title 在部分浏览器/读屏器不可达）。
- 模型页全部增删改动作收敛为弱化纯图标按钮（h-7 w-7、stone-400、透明底），hover 显示暖橙底色增强，Tooltip side=top 显示动作名；"新增模型"同为图标钮。编辑/删除移至模型行行尾，不再在展开区内独占一行；展开区仅保留编辑态的取消/保存文字钮以承载主次。空闲态门控（modelActionsIdle）统一约束头部与行尾动作，编辑期间行尾动作整体移除。
- 折叠动画：折叠体改为 grid-rows 0fr↔1fr 过渡容器（内容常挂载 + overflow-hidden + motion-reduce 降级），消除 v-if 卸载导致的布局突跳；行高以内联 `gridTemplateRows` 样式表达（修复任意值类未生效导致的一级折叠失效）；折叠态语义由 data-open/aria-hidden 表达。
- 迭代三（交互修复）：两一级区改为手风琴互斥（至多展开一个，默认提供商详情展开；begin* 进入任一侧编辑/创建时自动切换到对应区并收起另一侧）；全部层级改为整行 trigger 折叠（hover 背景包裹含尾部动作的整行、cursor-pointer），行尾动作区 `@click.stop` 特殊处理，chevron 降级为纯指示器（无独立 hover 底色、非按钮）；锁定说明挂在整行 title 上。
- 迭代四（密度）：一级区头 hover 仅 pointer 不加背景色；左列提供商行名字与协议/计数徽标同行尾部显示；读面字段改为"字段名+值"同行、按长度两栏排布（模型 ID 等长值跨两栏），协议入口压缩为单行（协议+认证左、URL 右截断）；卡片纵向 padding 与表单行距减半，能力输入/输出两列并排，编辑表单简单字段改内联标签。
- 模型视图三块（信息/能力/参数）单列纵排；已在提供商上下文内，去除"所属提供商"字段。能力 chips 仅图标，名称经 tooltip 呈现。参数去"tokens"字样，以 K/M 单位显示（256K=256000 十进制口径，与既有默认一致），输入框下方提供常规值徽标一键填入（上下文 32K–1M，输出 4K–128K）。
- 保存反馈（notice/error）上提至区块顶部：动作条位于各 section 头部与行尾，沉底反馈会滚出视口。

## 决策

工作台导航精简为：左栏一级键仅剩"设置"（+ 品牌/新对话/工作区/对话树）；观测经对话页右栏右上角浮动图标按钮进入（全宽常显，tooltip"观测"），页头统一命名"观测"，双 tab 门禁不变；模型配置仅从配置页"模型" tab 可达；ProviderConfigPage 采用"扁平提供商列 + 提供商详情/模型列表双一级折叠区 + 行内模型配置详情"的渲染矩阵。

## 承接自 0009 仍有效的决定

以下决定本次未动，因 0009 整篇接替而在此重述，继续有效：

1. Trace 与 metrics 收敛为二级页双 tab；Trace coding 专属，metrics 双模式可见（work 不渲染 trace tab）；模式切换启动竞态由 tab 可用性收敛处理，不弹回 home。
2. Trace 采用整页二级形态，返回路径单一（页内返回按钮回 home）。
3. 工具目录并入配置页第三个 tab；配置页为会话内受控 tab 容器（无 vue-router，非法 tab 回退通用）。
4. `useTraceProjection({ liveTurnEnabled })` 共享管线约定：HomeSidebar 以恒 false 消费。
5. 左栏工作区区段置顶优先级不变。

## 影响

- `SidebarNavigationPage` 收窄；App 派生高亮映射简化（config∧general→settings，其余 null）。tests 不被 vue-tsc 覆盖（include 仅 src），stub 合法性由运行时断言兜底。
- 折叠状态与展开模型行为组件内 ref，不持久化；配置页 tab 切走即随 ConfigPage 的 v-if 卸载整体重置（含未保存表单输入——与既有 tab 行为一致）。
- 残余风险：任一编辑态下点击左列另一提供商仍直接覆盖编辑器（沿袭旧布局语义，静默丢弃未保存输入）；后续可为脏表单加确认门槛。
- 既有缺陷登记（双审确认非本次引入，留后续任务）：① providers 异步加载期间进入模型 tab，watch immediate 会把页面钉在"新增提供商"态；② create 态保存失败重试会二次 `addProvider()` 产生孤儿半配置提供商。
- vitest coverage.include 清单与 `test:ui-guard` 文件集不变；ProviderConfigPage 新增专属 spec 但不入覆盖率测量。
- 后续 IA 调整继续走 `workspace-shell-navigation` spec 的 OpenSpec 变更流程。
