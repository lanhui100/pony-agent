# Wave 5.1 验收测试矩阵 (B088, B104, B098, B105)

| 任务 | 级别 | 契约验证 (L2-T) | 对抗破坏注入 (L2-AT) |
| :--- | :--- | :--- | :--- |
| **B088 (启动期 host-read 超时)** | L2 | 验证 `initializeSessions` 在 host 读取挂起时，触发有界超时，避免永久白屏。 | 模拟宿主挂起永不返回，断言系统在达到配置超时后主动终止并展示降级错误状态。 |
| **B104 (限流 4s 恢复窗口重试)** | L3 | 验证命中 rate_limit 时，若预计恢复窗口较短（如 4s），系统执行有界等待重试而非立即 Abort。 | 注入连续多次 429 响应，验证退避与重试耗尽后的安全 Abort 契约。 |
| **B098 (输入法守卫收窄)** | L2 | 验证输入法组合态 (keyCode 229) 下，Ctrl+Z 和 Alt+S 等快捷键不被吞掉，仅拦截回车提交。 | 注入快速按键组合序列，确保非 Enter 按键均正常穿透。 |
| **B105 (任务卡片自动换行)** | L1 | 验证 Team 任务卡片样式支持长标题/描述自然折行，不被纯 truncate 截断。 | 注入超长英文连续字符串及多行描述，验证 UI 排版无横向溢出。 |
