# docs/AGENTS.md —— 文档标准（每个事实一个家）

> 本文是 Pony Agent 文档体系的家索引：明确各类事实与知识的存放边界。
> 治理规则家载体为 **AGENTS.md**，人读契约为 **README.md**。

## 文档分层清单 (Tier 分类法)

| tier | 承载内容 | 规范路径 |
|---|---|---|
| **根 AGENTS.md** | 常载 standing orders、行为准则、全项目入口地图 | `AGENTS.md` |
| **文档标准** | tier 分类、写作规则、防腐化自查表 | `docs/AGENTS.md` (本文) |
| **工程宪章与治理根** | 项目核心不变承诺、成熟度状态、门禁声明 | `.meta/` |
| **决策记录** | 关键技术方案选型、为什么这样/为什么不这样、备选分析 | `docs/decisions/` |
| **任务系统** | 需求拆解卡片、进度看板、多智能体审核日志 | `management/task-system/` |
| **架构与设计指南** | 系统拓扑、模块交互、运行时设计 | `docs/architecture/` |
| **包与模块说明** | 单模块配置、语义、本地运行注意事项 | 各包 `README.md` |

## 写作规则

1. **事实单一真源（Single Source of Truth）**：
   - 决策不写在任务卡里，任务进度不写在代码注释里；
   - 任何方案决策落入 `docs/decisions/`，不再散落于对话。
2. **时态与状态自洽**：
   - 已落地的功能使用现在时叙述；
   - 被替代的旧方案标记 `superseded` 并移入对应归档目录。
3. **同提交原子性**：
   - 更改系统行为或增加关键依赖时，必须在同一次提交中同步更新对应的架构文档与 ADR。
