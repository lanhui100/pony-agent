## 4. PA-141 Draft 态宿主审批闸门（P1,B，用户裁定方案 b）

**设计约束（必须落地的公共 seam）**：
1. 审批证据类型 `PlanExecutionApproval` 公开、字段冻结：`session_id: String`、`plan_id: String`、`expires_at_ms: u64`；serde `camelCase` ⇒ JSON 键 `sessionId` / `planId` / `expiresAtMs`。
