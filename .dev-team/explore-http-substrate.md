## 覆盖盲区
1. `src-tauri` 的 `tauri-plugin-updater` 插件底层网络实现未纳入 core crate，桌面端的更新下载通道与 CLI/TUI 完全脱钩。
2. Windows 环境下对正在执行的二进制文件进行写盘替换时的锁定机制（如 `ERROR_ACCESS_DENIED`）在现有代码中无处理逻辑。
3. 现有 `retry.rs` 与 `retry_tool_timeout` 机制仅针对单次内存请求重试，未覆盖断点续传（HTTP Range 头）或大文件分块重试。
4. 网络出网代理支持：现有 `web_client` 与 `pinned_web_client` 均硬编码 `.no_proxy()`，但 `tui.rs` 的 `perform_update_check` 与 `provider` 未禁用环境代理，出网行为在不同组件间不一致。
